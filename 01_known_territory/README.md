## 使用规则

1. **先查本清单**：一个外部对象落在"已系统掌握"领域内 → 只记录新进展（放 `03_expansion_queue`，标注 `追新`），不写基础卡。
2. **覆盖深度变化**：某领域通过本仓库验证获得新资产后，回填更新这里的星级。
3. 星级的正式权威以飞书内库为准，本清单是探索侧的快照。
