# 05 · Scan Logs（探索扫描日志）

> 记录每次扫描：扫了什么、看到什么信号、收了几条线、状态如何。
> 目的：让探索过程**可回溯、可复盘**，避免重复扫描同一范围。

## 日志规范

- 按 `YYYY-MM/YYYY-MM-DD_<主题>_scan.md` 命名。
- 每次扫描记录：扫描时间 / 扫描主线 / 信息源 / 收线清单 / 筛选结果 / 下一步。
- 模板见 `99_templates/scan_log.md`。
