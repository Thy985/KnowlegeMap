# 99 · Templates（模板）

> 探索工作使用的标准化模板，保证每份产出可对比、可审计。

| 模板 | 用途 | 何时使用 |
|---|---|---|
| [candidate_card.md](candidate_card.md) | 候选对象证据卡 | 线索从 inbox 进入 candidates 时 |
| [scan_log.md](scan_log.md) | 扫描日志 | 每次周扫描后 |

## 使用要点

- 候选卡必须回答四问：**解决什么问题 / 为什么现在值得关注 / 与我什么连接 / 我怎么验证**。
- 证据分级沿用 FACT / DESIGN：FACT 需官方文档/源码/论文/Release/实测；DESIGN 仅博客/社区/趋势。
- 一条对象一张卡；重复对象复用旧卡并更新状态，不另开新卡。
